# AI 原创项目

项目页的「AI 创作」入口位于新建项目左侧。创建时选择文本、图片、视频模型、输出分辨率、共同画幅及创作手册；电影质感开关也在此设置。AI 项目的画幅、项目类型和电影质感在创建后不可更改。

进入新项目后，创作引导询问类型、章节数量和每章目标成片时长（总时长，不是单镜时长）。确认后创建持久化提案任务，返回 3–5 个故事方向。可选择其一，也可修改意见重新构思。选择后只生成精简大纲、设定和章名目录，不批量扩写章节。即使规划100章，也由用户进入章节后逐章创作正式剧本。

## 持久化与恢复

- `Project.creation_state` 保存当前阶段、用户意见、提案、最终选择和章节规划检查点；项目列表接口仅返回简要状态，完整内容由创作接口按需读取。
- `project_ai_creation` 使用现有 Worker、数据库队列、租约、费用账本和通知机制。请求创建后立即返回，不在 Web 请求里等待模型。
- 大纲完成后保存检查点。Worker 失去租约后重新排队；重试复用大纲，不再调用模型扩写全部章节。兼容旧检查点，保留之前已经完成的基础描写，其余章节仅建立待创作入口。
- 项目最终落库与任务成功状态在同一事务内提交，避免仅创建文件却没有真实章节。
- 对话记录、大纲、章节列表、每章基础内容、`创作记忆与设定.md` 都作为项目文件保存，可以下载。章节各自拥有独立的基础内容文件，避免删除一章连带其它章节。
- 创作记忆与设定文档可在项目文件库编辑；后续创作任务和导演对话读取最新内容。电影制作规范在系统提示中注入，不重复拼接到用户正文。
- 章节剧本生成同时请求1500字以内的连续性摘要，按剧本版本持久化为记忆文件。后续章节只注入最近两章对应生效版本的记忆；旧版本没有摘要时使用有限长度的结尾节选，不伪装成摘要。
- 大纲和设定注入分别限制3000和4000字符，完整文件仍保存。创作提案只传当前选择与最近4条有限长度反馈，不传检查点和全部历史。资产提示词任务不注入故事大纲、章节记忆和导演规划，只加载当前资产类型对应的画风规则，衍生资产另加对应衍生规则。移除不区分任务和模型的32000字符硬拦截；日志分别记录模板、技能、任务数据和系统指引的字符数，不记录凭据和正文。
- 剧本生成和修复均通过独立的 `continuity_summary` 字段保存记忆，正文 `content` 只包含剧本。入库前分离明确标注的内部记忆行；修复版本的记忆单独保存，避免下一章引用旧版状态。

## 制作约束

AI 项目仅解锁第一章。前面的章节均存在非空正式剧本版本后，才能进入下一章。无需等待审核、资产或视频全部完成。规则同时应用于章节读取、任务提交与 Worker 执行，前章重做后会重新计算后续章节可用性。

剧本、审核、资产提示词、分镜、视频提示词和导演对话使用项目文本模型。项目图片模型优先于全局按分辨率配置的默认路由；图片和视频使用项目固定画幅。创建及设置更新会校验模型声明的比例和分辨率。

电影质感规范涵盖剧情因果、动作受力、镜头目的与时长、机位轴线、光源连续性、材质、特效交互、角色表演与中文台词、声场层次和逐阶段验收。画风手册与模型能力仍然有效，不会因为电影质感强行改变画风或超出模型能力。

## 实现位置

- 创建表单：`apps/web/src/views/WorkspaceView.vue`
- 初始引导：`apps/web/src/components/AiCreationOnboarding.vue`
- 导演台与章节限制：`apps/web/src/views/DirectorView.vue`
- 创作接口：`apps/api/app/api/routes/ai_creation.py`
- 合同、约束与文件保存：`apps/api/app/services/ai_creation.py`
- 大纲和目录后台任务：`apps/api/app/services/ai_creation_worker.py`
- 数据迁移：`apps/api/migrations/versions/ab83e2196c40_add_ai_project_creation.py`
- 集成验证：`apps/api/tests/test_ai_creation.py`

已有部署更新时先执行 `python -m alembic -c apps/api/alembic.ini upgrade head`，然后重新编译前端并重启 API、Worker 和 Agent Runtime。积分管理增加「AI 项目创作」计费项，按一次提案或一次大纲与目录规划计费；逐章剧本创作使用现有剧本任务计费，失败按现有规则退款。
