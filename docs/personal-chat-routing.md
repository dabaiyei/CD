# 首页对话的 JEV 意图路由

普通对话模式调用管理页选定的 JEV 平台，判断本轮应交付文字、图片、视频还是澄清问题。支持 Typesafe SystemOne（`jev-1.13.0`）和 OpenCode Zen（`jev-1.13-free`）。项目 Agent 和 AI 全自动也接入局部辅助判断，详见 [项目 JEV 辅助判断](project-jev.md)；保留原有阶段调度及生成模型。

JEV 只接收有限的文字上下文、图片 ID/上传序号和可用媒体模型名称，不接收图片二进制或供应商密钥。图片内容理解仍由原对话模型完成。实际调用生成平台的权限由后端控制，低置信度的媒体动作不会执行。

会话的 `runtime_manifest.media_creation` 保存创作要求、参考附件 ID、实际选中的模型和参数。连续修改继承状态；新主题重新使用默认模型。用户上传图和生成结果分别编号，不会因为又生成一张图导致“第一张上传图”变成另一张。重试复用任务中保存的路由。显式选择技能或授权优化提示词时才使用对话模型改写；否则保留原始要求，连续修改按时间追加用户要求。

管理入口：**管理 → JEV 意图路由**（`/admin/jev`）。管理员可以启停、更换密钥与模型、设置超时和媒体置信度阈值，并测试已保存的连接。配置按租户隔离，加密存储密钥，接口不返回明文。保存后新请求立即生效；进行中任务及其重试保留原路由。

平台选择支持 `typesafe` 和 `opencode_zen`，分别保存密钥及模型；切换不会把旧平台密钥发送给新平台。Zen 使用 `https://opencode.ai/zen/v1/systemone`；免费模型的限额、可用性以平台为准，不承诺永久免费或不限量。未传平台的旧客户端继续操作当前平台；首次启用新平台必须先填写该平台密钥。测试连接直接调用已保存的平台，不经过可选的 Laya 预判。

Zen 遇到本机域名解析错误或 TLS 主机名不匹配时，使用 Cloudflare DNS-over-HTTPS 获取该固定域名的公网地址，仍严格校验 `opencode.ai` 的 TLS 证书和 SNI；不会关闭 HTTPS 校验。DNS 请求不携带密钥或对话，结果按 TTL 缓存、最多 300 秒。仅连接阶段失败可回退；HTTP 错误或已发送推理请求的超时不自动重试，全部过程受原请求超时限制。正常解析不受影响。Docker 更新先执行 `alembic upgrade head`，创建平台配置表并保留原 Typesafe 配置。

未保存独立配置时，兼容读取 Git 忽略的 `.env.jev`：

```dotenv
TYPESAFE_API_KEY=替换为自己的密钥
TYPESAFE_MODEL=jev-1.13.0
TYPESAFE_TIMEOUT_SECONDS=8
TYPESAFE_ROUTE_CONFIDENCE=0.65
```

Docker 部署可直接通过管理页设置，API 和 worker 共享数据库配置。环境变量仅作为尚未配置时的回退；页面显式关闭或清除密钥后，不会被环境变量重新启用。仅修改环境变量时需要重启 API/worker。

验证：`PYTHONPATH=apps/api`，执行 `python scripts/probe_personal_routing.py` 会真实调用 JEV，有少量分类接口费用，但不会生成图片/视频。`pytest apps/api/tests/test_personal_routing.py` 使用模拟分类和媒体平台，验证真实任务链路、附件传递、连续参数继承及异常阻断，不收费。

JEV 是概率分类器，不能保证所有自然语言均无歧义。接口异常或无法可靠决定媒体交付时，仍调用原聊天模型结合本窗口上下文回答文字问题或针对缺失信息澄清，但禁止付费媒体生成，不再直接返回固定追问。

每个窗口用独立的 session 保存对话。最近最多 10 条消息、16000 字符直接传入模型，单条超过 6000 字符时压缩；会话摘要补充更早的背景，不再排除摘要已经覆盖的最近消息。首页会话原文及生成媒体的提示词、规格另外作为只读 `conversation-history` 文件提供，模型可按需检索，不把全量记录塞进上下文。文件只包含本用户、本租户、当前会话的既有消息，不跨窗口混用；编辑或删除后下次请求从数据库重新构建。

连续媒体方案使用独立的“第 1 步”“第 2 步”标题和每步完整的引用块提示词，平台保留原文、模型、参数、参考图以及完成位置。对已明确方案回复“开始/提交/继续”会执行下一步；只有用户授权自动续接时才自动排后续任务。“先出图给我看”保持单步。JEV 负责识别执行/讨论与自动续接授权，不能用助手自称获准代替用户授权。

每一步是独立扣费、独立失败重试的任务；前一步保存成果与创建下一步在同一事务内完成。图片转视频自动使用上一步生成图，并先由视觉模型核验明确画面要求，未通过则暂停。后续失败保留已完成图片，用户继续时从当前步骤恢复。自动续接消息标记为“系统自动续接”，不会伪装成用户新要求。不支持解析的自由格式方案会留在讨论阶段，不承诺任意文字计划均可自动执行。

图片接口建立连接/TLS握手失败时，在同一请求格式上最多尝试三次，保持请求体和幂等键，不因首个格式探测失败而立即中断；平台持续不可达仍会明确失败，不关闭证书校验。
# 对话记忆边界

首页对话的长期记忆仅检索当前 `source_session_id`，不再将所有 `project_id=NULL`
的记忆视为个人共享池。未标明来源会话的旧记忆不会自动注入首页对话。
自动提取的首页记忆使用会话独立的键，防止不同窗口同名记忆互相覆盖。
项目助手及项目生成链路仅检索当前项目 ID 下、同一租户及用户的记忆；同项目内可共享。
每个窗口的摘要、消息历史与附件仍按原会话读取。此变更不删除既有记忆或聊天记录。
