# 无限画布视频分析

选中视频后，在视频节点上方工具栏点击「视频解析」。一次操作先保存带时间戳的关键帧组，再使用同一批证据图分析，生成可保存的连续结构化时间轴；不再把分析与抽帧拆成两个顶部按钮。需要替换人物或补充要求时，先把人物图片、图片组或文字节点连入视频节点，解析会一起读取；Codex 也可通过 referenceNodeIds 指定参考。解析结果节点展示各段参考图、动作、运镜、光线及中文复刻提示词，原视频与人物图保留不变。画布助手直接读取视频、普通文本连线分析仍可用。

解析结果的「创建复刻配置」将本段真实关键帧、人物替换图和时间轴连接到视频生成配置，按当前模型支持的时长和参考图额度准备参数，点击后可检查再生成。镜头划分依据叙事与切点，不把每张取样图拆成独立视频。首尾帧模型要替换人物时，需要先用关键帧和人物图改图，不能把人物设定图直接当首帧。直接引用解析结果的文本生成与组装提示词也会读取它关联的图像证据。

复用 `replica_reading.contact_sheets` 的 Hypit 证据排版，使用本地 FFmpeg/FFprobe 精确抽取时间戳画面，压缩成 WebP，再交给支持图片的文本模型。不要求原生视频输入接口，不依赖 WhisperX 安装。音频不会因抽帧自动变成对白；需要对白时应连接真实转写文本作为证据。

快速变装与闪切默认使用 `adaptive`：扫描分析范围内明显画面变化，优先保留变化前后实际帧，其余额度补充概览帧。变化可能是遮挡或闪光，并不一定是剪辑；结果记录检测到与已覆盖的变化数，取帧预算不足时不能承诺完整还原。`sampling=uniform` 可选择原等间隔策略；`times` 可按原片秒数精确补取。解析需保留变装前后服装、站位、触发动作、遮挡/闪白、构图、方向及时间，不能只写“顺滑转场”。模型遗漏选择转场参考时，解析器仍保留本段实际前后帧。

创建复刻配置时，模型声明支持全能视频参考且接受 MP4，会自动截取本段实际原片作为视频参考，同时连接人物图和时间轴。原片时间映射到从0秒开始的任务时间，保留动作与转场节拍。仅支持图片参考的模型仍读取真实关键帧；额度不足以保留关键前后状态时明确提示，不静默删掉证据。供应商的视频参考能力、人物替换能力仍决定最终还原效果。

视频节点工具栏还提供「提取音轨」「封装音轨」。封装弹窗可选择当前画布音频，设置音频从第几秒开始及在视频第几秒播放；生成新视频，替换旧音轨，短音轨补静音、长音轨按画面时长截断，原文件不变。MP4可直接封装的画面编码保持不变，不兼容的编码转换为 H.264；音轨使用 AAC。无音轨或范围无效会显示具体错误。本地处理无需模型调用或积分。

账号素材通过 `/api/v1/canvas/video-evidence` 读取，不能指定服务器文件路径或任意下载 URL。关键帧及取样图按账号保存；模型生成沿用现有任务、积分、失败退款和自定义渠道。直接通过 `/canvas/generate` 给文本模型传视频参考也会由 Worker 自动抽帧，任务使用提交时的独立素材副本。

Codex/MCP 工具：

- `canvas_analyze_video(nodeId, prompt?, model?, referenceNodeIds?, count?, start?, end?, sampling?, times?)`：抽帧并启动结构化解析，返回分析配置、关键帧组和时间戳图片节点。
- `canvas_get_video_analysis(nodeId)`：查询状态、连续时间轴、原视频与实际参考图片关系；复刻需把本段图像和文本一起传给模型，不能只用文字。
- `canvas_extract_video_frames(nodeId, count?, start?, end?, sampling?, times?)`：创建带时间戳的图片节点并关联原片，适合局部检查、精确补帧与长视频分段分析。
- `canvas_create_video_replica(nodeId, segmentIndex)`：从结果文本节点创建对应段的完整复刻配置，再用 canvas_run_generation 启动。
- `canvas_extract_audio(nodeId, start?, end?)`：提取原片音轨或对应片段音轨。
- `canvas_trim_video(nodeId, start, end)`：精确截取原片参考片段。
- `canvas_mux_audio(nodeId, audioNodeId?, audioStart?, offset?)`：把音轨封装到现有视频，默认使用唯一连入的音频节点，也可明确指定。

媒体工具立即返回处理节点，用 `generation_get_status` 查询到成功后再引用；失败节点保存原因，不把提交误当成完成。媒体端点 `/api/v1/canvas/media-process` 同样只接受当前账号素材键。

沿用原 Hypit 上传100MB及单次分析180秒范围；长视频可按时间段抽帧。默认16张，支持2–32张；取样不能代替逐帧证据，应区分可见事实、推断与盲区，不能将取样帧机械拆成互不连续的视频任务。配置的自定义 OpenAI/Gemini 渠道和文本调用脚本同样收到图片证据与用户指定的参考图。
