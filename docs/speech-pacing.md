# 人声语速与视频时长

分镜生成阶段先安排台词、语速、停顿和动作，再选当前视频模型的合法片段时长。六档参考语速分别为 90–110、120–140、150–170、180–200、210–230 和 240 字/分钟以上（第六档初始估算使用 240–280）。未指定时默认第三级。

可在动作描述中写 `语速4级`，或逐人写 `甲（语速1级）：台词`。多人轮流对白按各自语速累加并留换人间隔。括注、角色名、时间码与后期字幕不算台词；明确停顿另计。行走等级仅在边走边说时作为参考，旁白与心声不因奔跑被迫加速。

新分镜在模型支持更长时长时，会局部修正时长及关联动作/表情时间轴，保留台词。超过模型最大时长的内容由支持插入镜头的审核修复流程拆镜；不在只能修一个镜头的格式校验中无限重试。固定原始时间轴保持不变，由审核指出冲突并在允许范围内处理。预算是启发式估算，不是配音实测时长。

项目视频提示词与最终提交、首页视频最终提交共用语速指令。首页仅提取明确引用的台词；未指定时长时选足够的合法档位，超出单条视频容量时明确提示分段，不擅自删词或提速。静音提交移除本模块的发声指令；旁白不要求角色口型同步。已有视频不会被重新生成。
