# Laya 中文路由适配

Laya 作为首页个人会话 JEV 前的可选本地判断器，默认关闭。不修改现有
JEV 密钥、项目审核或项目自动制作链路。低把握、长输入、参考图复杂指代、
提示词改写授权和未明确授权的计划均回退原 JEV 路径。

## 请求

使用 `/v1/systemone`、`model=auto`。所有问题说明为中文字符串；仅询问
当前相关的输出类型、旧作品续接、任务操作、连续执行与提示词改写。
不发送模型目录、完整历史、完整提示词、附件字节、密钥。
仅遇到指代追问时附已有作品类型及最多160字符摘要。当前消息超过1200字符
整笔回退，不截断尾部否定或授权。参考附件编号与归属仍由数据库和后端规则处理。

## 阈值与限制

2026-09-30 对用户本地 `192.168.88.110:28180` 的 `auto` 服务实测：

- 校准集16条：输出分类原始正确9/16。
- 独立留出集12条：原始正确6/12。
- 在校准集选择零错误且覆盖最多的候选门槛：最高选项概率至少0.95，
  与第二名差值至少0.50；校准集原始预测直接接纳5/16。
- 加入明确文字/否定指令规则后，校准集正确采纳8/16，留出集8/12，
  其余弃权。这里是输出判断，不是端到端任务成功率；生产完整性检查可能进一步回退。
- 12条带作品/计划状态的场景复测，单次约0.15–0.37秒，
  输入用量126–392 tokens（多问题合计口径），原始关键分类仍只有6/12正确。

不沿用 JEV 的0.65 confidence：Laya的confidence与选项概率是不同量。
保留原始confidence，另用内部`_laya_accepted`标记门槛结果，不伪造概率。
续接类型暂用保守0.95/0.50门槛，尚未完成独立校准；不宣称已验证准确率。
执行、自动续接、改写等授权不接受Laya模型单独授予，明确指令走代码，其余回退。
取消指令优先于模型的execute误判。

本次样本少、非随机抽样，不能外推生产准确率。当前结论是选择性本地分流，
不是完整替代JEV；更换权重、问题模板或服务版本需要重新校准。

## 可选启用配置

部署环境支持：

```dotenv
LAYA_ROUTING_ENABLED=true
LAYA_BASE_URL=http://192.168.88.110:28180
LAYA_API_KEY=<本地服务密钥>
LAYA_TIMEOUT_SECONDS=3
```

保留有效JEV配置供回退，修改后重启API/Worker。默认未启用，测试密钥没有写入仓库。

## 验证

`scripts/calibrate_laya.py` 从 `LAYA_PROBE_URL` / `LAYA_PROBE_KEY` 读取测试连接，
只做模型判断，将完整校准/留出结果写到 `.logs/laya-calibration.json`。
`scripts/probe_laya_routing.py` 设置 `LAYA_PROBE_NATIVE=1` 可复测专用适配器；
设置 `LAYA_PROBE_MODEL=auto` 使用部署的自动选择。
这些脚本不会提交媒体生成任务或切换站点配置。

## JEV 同批对照（2026-09-30）

在修正组合意图规则后，用相同的40条中文请求分别调用本地 Laya `auto`
及当前已配置的 JEV `jev-1.13.0`；只做路由判断，不提交媒体任务。
结果文件：`.logs/laya-latest-holdout.json`。

| 指标 | Laya | JEV |
|---|---:|---:|
| 原始分类正确 | 26/40（65%） | 40/40（100%） |
| 最终路由正确 | 20/40（50%） | 38/40（95%） |
| 本地/直接处理 | 20/40（50%） | 40/40 |
| 直接处理正确率 | 20/20（100%） | 38/40（95%） |
| 平均单次响应 | 0.161 秒 | 0.641 秒 |
| 最长单次响应 | 0.337 秒 | 0.713 秒 |

Laya仅在高阈值通过的样本直接路由，故覆盖率低；这个小样本的20/20不能解释为
生产准确率。JEV两条最终路由差异：未提供图片却要求记住“第三张照片”时，
系统因附件不存在而澄清；“不要生成图片，改为生成视频”被意图层识别为视频，
但现有参考图状态校验将路由收敛为澄清。后一项是共享路由校验差异，不是JEV
原始分类错误。该组是人工构造的小型对照集，不是生产流量随机抽样。
