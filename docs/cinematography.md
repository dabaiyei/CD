# 共用镜头语言

规则实现位于 `apps/api/app/services/cinematography.py`。项目手动/全自动分镜、单镜修复与审核、普通视频提示词、独立打斗编排、首页及项目助手的视频提示词写作共用这套语义。复刻视频的重新编排也使用相同术语，但保留原片的运镜和切点，不擅自重新导演。首帧生图只接收取景、静态光学/布光/配色说明与原有静态空间约束，不接收运镜、跟焦、快门和动态配方。

不改写用户要求原样提交的提示词，不修改已保存的分镜或已生成的视频。关闭 JEV 时仍可使用这套镜头语言；启用时沿用 JEV 的创作授权与模块选择，不为摄影再增加一个模型判断调用。

## 术语校正

| 方式 | 物理变化 | 应写清楚 |
| --- | --- | --- |
| 固定 Locked-off | 位置、朝向不动 | 人物或环境是否运动 |
| 推/拉 Dolly in/out | 机位靠近/远离 | 从什么构图到什么构图、推进动机与速度 |
| 摇 Pan | 固定机位水平转向 | 起止目标、方向与转动速度 |
| 俯仰 Tilt | 固定机位上下转向 | 从哪个细节到哪个细节；不是升降 |
| 移 Truck/Slide | 机位横向或斜向平移 | 路径、前后景视差、遮挡揭示 |
| 跟 Tracking | 跟随主体位移 | 跟谁、前/侧/后跟、相对速度 |
| 升降 Pedestal/Crane | 整机高度改变 | 起止高度、观察方向、空间揭示 |
| 环绕 Arc/Orbit | 围绕目标走弧线 | 方向、终点、跨轴如何交代 |
| 变焦 Zoom | 焦距改变 | 画面范围变化，不能冒充机位位移 |
| 移焦 Rack focus | 清晰焦点转移 | 起止对象、触发时刻；不改变人物站位 |

景别与运镜相互独立。大远景强调地理环境，远景保留大量环境，全景保留完整头脚与动作余量；中景/近景明确写膝部、腰部、胸部或肩部以上，特写以脸或对象局部为主，大特写突出关键细部。膝上常称 MLS，腰上常称 MS，胸上常称 MCU，各手册可能采用不同中文名称；实际裁切边界比缩写更重要。物体以自身整体为参照。

## 场景应用

每次使用一份约两千字的核心规则，分镜/视频加上阶段说明约两千四百字；局部视频写作至多补两张场景参考卡，不全量塞入手册。首帧只增加约五百五十字的静态画面规则。卡片仅供参考，不因提及“昨天的打斗”就增加交手。未命中特定类型的场景仍使用通用镜头规则，不增加模型判断调用。

| 场景 | 设计重点 |
| --- | --- |
| 对话 | 双人位置、视线与反打；按情绪/信息变化切镜，保留倾听反应 |
| 情感 | 稳定近景、微表情与停留；有心理转折才推进 |
| 悬疑恐怖 | 留白、遮挡与信息延迟；揭示才动，不凭空增加惊吓事件 |
| 打斗/追逐 | 完整动作关系、同速跟拍与清楚接触；切点承接动量，不能靠甩镜遮住招式 |
| 环境/巨物 | 先有尺度与方位锚点，再通过拉远、平移、升降逐层揭示 |
| 物件/线索 | 接视线或触碰的细节镜头；有明确目标的移焦 |
| 日常/纪实 | 固定、缓移或适度跟拍，保留自然节奏，避免无动机炫技 |

每个连续镜头通常一个主运动，必要时配合转向或移焦。不是每个镜头都要动，也不是每1—2秒必须切镜。空间轴线、屏幕方向、光源方向、动作相位、视线与焦点要连续；有意越轴需桥接，避免无意跳切。手持、甩镜、荷兰角、变焦冲击等特殊表达只在有明确叙事依据时使用，不作为“高级感”默认模板。

例：`0—3秒：双人中景，腰部以上，同侧平视固定机位；乙说完后目光落向桌上钥匙。3—5秒：保持机位不动，焦点从乙转至前景钥匙，钥匙的纹路逐渐清晰。` 这是固定机位配合移焦，不是推进；前提是剧本已有钥匙与这个视线动作，不能为套示例增加道具或剧情。

## 落位与审核

`shot_type` 保存开场景别，`frame_layout` 和 `image_prompt` 描述0秒构图；运镜过程、结束状态与切点放 `action_description` 或 `internal_shots[].description`。打斗详设保存在 `beats[].camera`，照明放 `lighting`，编译提示词时保留，不二次概括掉。

尊重项目画幅、模型时长、参考图能力、音频设置、一镜到底及固定机位约束；镜头语言不能制造新的平台能力。首帧不是多机位拼贴；未开启首帧接续时不引入对前段实际尾帧的依赖。

审核只报告有证据的物理/时间/连续性冲突；缺少焦距数值、摄影设备名、某种运镜或不同景别命名不构成失败。沿用现有单镜字段修复与断点，不新加整章审核循环，也不因新规则强制重做旧作品。实际生成质量仍受模型遵循提示词的能力影响。

## 完整摄影规范对照（v2）

依据用户提供的《影视镜头摄影参数完整规范.md》逐项补充。保留原始桌面文档；这里记录融合后的规则与校正，不把示例 JSON 变成新的输出协议。七个维度可分别描述，但光学、运动、曝光等相互影响，不能任意组合互斥参数。

| 维度 | 融合内容 | 现有字段与使用阶段 |
| --- | --- | --- |
| 场面调度 | 面对面、并排、纵深、高低、三角站位；横移、纵深、转身、绕行；中心/三分/框架/留白/引导线/三角/对称/对角线构图 | 静态进 `frame_layout.subjects/spatial_relations`、`scene_description`、`image_prompt`；运动进 `action_description` |
| 景别 | 取景物理边界、头脚余量、起止景别；不因中英命名差异重写 | `shot_type`、`frame_layout.shot_size`、片内镜头描述 |
| 运镜 | 固定、推拉、摇/俯仰、横移、跟、升降、环绕；运动方向、速度、加减速及相对速度 | `action_description`、`internal_shots[].description`、打斗 `beats[].camera` |
| 光学 | 焦距/画幅与视角，机位与透视，多因素景深；固定焦点、跟焦、移焦区分 | 静态视角/清晰范围进 `frame_layout.camera_position` 并同步 `image_prompt`，使打斗阶段精简图片提示词后仍能继承；跟焦/移焦进动作描述或打斗 `camera` |
| 灯光 | 主/辅/轮廓/背景/局部修饰光、实景光；顺侧逆顶底光，软硬、光比、白平衡与混合光源 | `frame_layout.lighting`、`image_prompt`；打斗每段 `lighting`；普通视频承接已定光源 |
| 色彩 | 主辅点缀色；邻近/互补/单色/分裂互补；饱和度、明度、肤色与服装识别色连续 | `frame_layout.visual_style`、`image_prompt`；打斗 `setting`；受原画风约束 |
| 成像 | 动作相位与模糊、快门/帧率区别、曝光和白平衡稳定、高光暗部层次、颗粒与噪点 | 视频写作规则；平台实参仍由真实模型能力和项目设置决定 |

只补未定项：用户明确设定、既有画风、资产身份/服装颜色、已定布局、原剧情与时间轴不被通用摄影示例覆盖。对白、情感、日常、悬疑、环境和道具镜头都使用这些基础规则；并非只应用于打斗。

## 源文档中的校正

1. **移与俯仰**：Tilt 是机位不动的上下转向；横向移镜是 Truck/Slide；升降是整机高度变化。
2. **焦距与透视**：透视由观察位置与距离决定，焦距与画幅决定视角。固定机位改变焦距并裁成相同构图不会凭空压缩透视；常说的长焦压缩往往来自为维持主体大小而后退机位。焦距数值须说明全画幅等效，不把 50mm 当通用“人眼参数”。
3. **景深与焦点**：景深不由光圈单独决定，还受焦距、对焦距离、画幅及清晰度判定影响。跟焦保持运动主体清晰；移焦把清晰对象从 A 转到 B。推进且主体距离改变时，固定对焦距离可能失焦；双人戏不自动套极浅景深。
4. **灯光定义**：主光负责塑形，不必是画内最亮物体或来自前侧45度。Practical 是画内实景灯，眼神光/修饰光另述；逆光不自动等于剪影。软硬取决于光源相对主体的视角大小，与光比是不同维度，软光也可以高反差。
5. **色温、光比、色彩**：光源冷暖须结合白平衡理解；烛光并不固定在2700–3200K，月光也不是固定蓝光。数值光比需区分主光:辅光与亮部:暗部。低照度、低明度、高反差互不等同；冷暖和高低饱和只是可选表达，不是题材情绪的硬映射。
6. **轴线与调度**：180度是维持空间可读性的连续性惯例，不要求人物永远固定左右。连续可见的走位或越轴可以改变关系；单插一张空镜不自动修复空间混乱。高低站位也不必然代表强弱。
7. **成像能力**：180度快门对应曝光时间约为 `1/(2×fps)`，是常见风格而非唯一“自然”标准；90度等小快门角在低帧率可能更跳，不默认用于流畅打斗。提高帧率不自动补齐丢失的动作或保证小模糊。24/25/30/48/60均不作为通用强制值，分辨率也不是实际细节质量的保证。
8. **HDR与质感**：保留场景高光/暗部细节与输出HDR编码不是同一件事；提示词写8K/HDR不会升级接口能力。数字噪点不是胶片颗粒，不靠时间闪烁或过度磨皮制造质感。

## 四类模板的修正用法

模板只提供选择方向，不强迫已定镜头改造型、光线或切点；对应建议已合并进按需场景卡。

| 模板 | 正确组合与边界 |
| --- | --- |
| 双人对话 | 保持视线和轴线，清晰范围覆盖需要读表情的人；按已有光源补暗部，不默认浅景深、固定对焦距离、三点布光或24fps |
| 动作追逐 | 主体与接触面清晰，同速跟拍与跟焦，动作相位连贯；不默认冷色硬光、小快门角、爆闪或密集甩镜 |
| 恐怖悬疑 | 利用遮挡、留白和信息延迟；暗部仍保留叙事信息；同一区域不能同时要求互斥的高低光比，不一律套底光/冷调 |
| 宏大环境 | 有尺度锚点；主体静止、焦距固定时拉远通常由全景/远景走向大远景，而非反过来；升高是否改变景别取决于距离和观察方向 |

执行层不增加相机设置面板或七维必填字段，不全量加载此文档，不新增审核轮次。核验只针对已有明确描述之间的冲突；缺参数不判失败。复刻仍以原片为准，普通原样媒体提交仍不被自动润色。
