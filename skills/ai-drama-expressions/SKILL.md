# AI 漫剧人物表情提示词

帮助用户为 AI 漫剧/短剧写出"有戏"的人物表情提示词。核心原则：**表情不是一个词，而是一段表演**——"女主很伤心"是无效写法，把眼神、眉毛、嘴角、身体反应、剧情状态说清楚才是有效写法。

## 工作流程

1. **明确需求**：确认场景（什么剧情状态）、角色、主情绪。一条镜头只选一种主情绪。
2. **查找表情**：先在 `references/expressions.md` 中查找是否已有匹配的表情提示词，直接复制使用。
3. **库中没有时**：用下方"万能表情公式"现场创造新表情。
4. **组装镜头提示词**：按固定结构输出。

## 万能表情公式（创造新表情的规范）

任何情绪都拆成 5 个部分描写，缺一个表情就"没戏"：

| 要素 | 要回答的问题 | 示例 |
|------|------------|------|
| 眼神 | 看向哪里？躲闪/发亮/失焦/盯住？ | 眼神从克制转为震惊，瞳孔微微放大 |
| 眉毛 | 放松/上扬/压低/皱起？ | 眉头慢慢舒展 |
| 嘴角和嘴唇 | 抿住/颤抖/张开/压住笑？ | 嘴唇微张但没有说话 |
| 身体反应 | 后退/前倾/攥紧手/肩膀放下？ | 手指慢慢攥紧 |
| 剧情状态 | 此刻刚发生了什么？ | 刚听到真相 / 被背叛 / 终于释然 |

**创造新表情的步骤**：

1. 先用一句话说出情绪的本质（不是"悲伤"，而是"信念被击碎后的空"）。
2. 按公式逐项描写：眼神 → 眉毛 → 嘴唇 → 身体反应，每一项都指向情绪的本质。
3. 加一个"像……"的比喻句收尾，帮模型理解表演的意图（如"像已经发现了问题"）。
4. 强度分层：同一种情绪至少想出三个强度档（轻微/中等/极致），例如悲伤 = 隐忍难过 → 无声落泪 → 崩溃大哭。默认推荐中等档，除非剧情明确需要爆发。
5. 自查：这条提示词里有没有身体反应？只有脸没有身体的表情是新手最大的坑——手、肩膀、呼吸、后退半步往往比脸更真实。

**新表情写法模板**：

```
[情绪名]：[眼神描写]，[眉毛描写]，[嘴角/嘴唇描写]，[身体反应]，像[表演意图比喻]。
```

示例（库外自创"听到噩耗后的职业性冷静"）：
> 听到噩耗后的职业性冷静：眼神在听到关键词的瞬间定住，眉头没有动，嘴唇缓慢地抿成一条线，握着杯子的手指指节泛白却保持坐姿端正，像多年的训练替他挡下了这一击。

## 镜头提示词组装结构

```
[角色设定] + [表情提示词] + [场景情绪] + [镜头景别] + [光影风格]
```

完整示例：

> 白衣少年站在雨夜院门前，眼神从克制转为震惊，瞳孔微微放大，嘴唇张开但没有说话，手指慢慢攥紧，镜头从中景缓慢推到面部特写，冷蓝雨夜电影光影，5秒。

关键规则：

- 表情戏优先用**近景或面部特写**，远景看不清情绪。
- 一场戏的情绪要有**递进**（如：强装镇定 → 发现真相 → 含泪愤怒 → 下定决心），不要突然爆炸。
- 不要堆砌"极度、强烈、震撼"，情绪太满反而没层次。
- 表情提示词可直接插入即梦、可灵、Seedance、SEKO 等工具，也可先生成角色表情参考图。

## 60 种固定表情库

**使用前必读 `references/expressions.md`**。六大类各 10 种：

1. 基础微表情（平静克制、欲言又止、强装镇定……）
2. 开心和松弛（浅浅开心、久别重逢、喜极而泣……）
3. 紧张和恐惧（突然警觉、强烈恐惧、大脑空白……）
4. 悲伤和崩溃（隐忍难过、无声落泪、崩溃大哭……）
5. 愤怒和对抗（忍着怒气、冷笑反击、含泪愤怒……）
6. 复杂情绪和戏剧转折（笑里藏刀、强颜欢笑、下定决心……）

每种表情都是"情绪名：完整描写"格式，可直接复制进镜头提示词。若用户的情绪需求跨类（如"含泪愤怒"在愤怒类），先查最接近的一类，再决定是否用万能公式微调。

## 避坑清单（写给用户的建议，输出提示词时顺带提醒）

1. 不要一条镜头塞三种主情绪（又开心又愤怒又害怕）。
2. 不要只写脸——身体反应是表演真实感的关键。
3. 失败时先诊断原因（角色图问题/表情词问题/镜头距离问题/场景情绪问题），不要盲目重抽。
