# 导演手册扩充包

新增八套独立叙事手册，每套固定三个文件，按现有平台阶段路由读取。原有手册不覆盖，项目已选手册不替换。

安装：在仓库根目录执行 `.venv/Scripts/python.exe scripts/import_director_handbook_pack.py --tenant-id <租户ID> --apply`。去掉 `--apply` 仅校验。重复运行保留同名手册的管理员编辑。

封面提示词在 `cover-prompts.jsonl`。通过 `scripts/generate_handbook_covers.py --kind director --model-id <系统图片模型ID>` 调用系统配置的图片供应商生成，原图存放于 `output/imagegen/director-handbooks-2026-09`，已有图片会跳过。生图会消耗供应商额度。内容安装完成后，导入命令添加 `--attach-covers` 可绑定生成的封面，仅补充没有封面的手册，不覆盖已有封面。

- 悬疑推理：以公平线索、信息差和证据反转推进剧情，适合调查、犯罪谜案与心理悬念。
- 都市爱情：以潜台词、双向选择和关系距离组织镜头，适合都市恋爱、重逢与情感拉扯。
- 权谋博弈：用目标、筹码、信息与代价构建攻防，适合宫廷、商战、组织竞争与谈判。
- 逆袭成长：以能力积累、兑现伏笔和可见成果组织爽点，适合职场逆袭、竞赛与身份反转。
- 动作武侠：强调空间、攻防因果与连贯动作，适合武侠决斗、追逐、救援和动作短剧。
- 奇幻冒险：用世界规则、探索目标与队伍协作驱动旅程，适合仙幻、异世界与秘境冒险。
- 科幻悬念：以技术规则、异常验证和伦理选择组织叙事，适合近未来、太空与人工智能题材。
- 生活治愈：以日常细节、倾听和微小改变建立情绪余韵，适合生活流、陪伴与温柔成长。
