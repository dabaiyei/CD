# 厚涂史诗 2D

高完成度厚涂叙事插画，大笔触组织体积，人物面部精细，边缘虚实有控制。主色体系：赭红、群青、暖象牙白与暗金。

## 每镜记录
scene_description 写空间和光源；action_description 写入镜、动作推进、出镜及剪辑切点；image_prompt 写入镜首帧；dialogue 写实际台词；video_prompt 在分镜阶段保持空值。

## 动作与运镜
层次鲜明的大景与人物中近景交替，缓推或稳定横移，避免透视跳变。画面保留厚涂质感但身体必须连续运动；笔触附着物体表面，不能沸腾闪烁，披风惯性随转身推进。为重心转移、接触、行走路径和反应留出时间，不能在一个短镜头里从多个动作结果间跳跃。先核对模型时长，再确定叙事节奏。

## 光源和环境
大面积侧光与空气透视，主体脸部有反射补光，明暗交界清楚但不过度硬切。环境运动遵循空间方向，不用背景高速运动制造主体动作感。首尾的光源、持物、视线和运动方向要能接上。

## 审核清单
核对角色身份与妆容、资产引用、动作负荷、首帧冲突、机位轴线、参考数量和台词原文。发现不连续要指出镜号与缺失阶段，给出延长、拆镜或修正动作路径的具体建议。除非分镜明确要求，不擅自添加闪白、黑场、定格、跳切或速度突变。
