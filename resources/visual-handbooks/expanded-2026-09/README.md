## 安装与校验

在仓库根目录执行：

```powershell
.venv/Scripts/python.exe scripts/import_visual_handbook_pack.py --tenant-id <目标租户ID>
.venv/Scripts/python.exe scripts/import_visual_handbook_pack.py --tenant-id <目标租户ID> --apply
```

默认只校验源文件，`--apply` 才创建数据库记录、Skills 技能包和封面媒体。默认安装前需要生成所有封面；接口不可用时可加 `--allow-missing-covers` 先安装手册。重复运行保留同名手册，不覆盖管理员编辑，也不批量修改项目绑定；如果已有手册尚无封面且生成文件已经补齐，则只补封面。

封面原始提示词见 `cover-prompts.jsonl`；生成文件位于 `output/imagegen/visual-handbooks-2026-09/`。封面通过指定 OpenAI 兼容接口生成，API Key 只在进程环境中使用，不包含在本资源包。

## 使用系统已配置的模型补图

```powershell
.venv/Scripts/python.exe scripts/generate_handbook_covers.py --model-id <系统图片模型数据库ID>
.venv/Scripts/python.exe scripts/import_visual_handbook_pack.py --tenant-id <目标租户ID> --apply
```

生成脚本复用应用的供应商凭据、接口地址、模型参数和生图网关，不另存 API Key。已生成并可解码的图片会跳过，避免重复提交；最多并发两张且不超过平台配置的并发数。模型返回的图片会规范为 PNG，导入后使用系统 WebP 存储。

实际验证：域名入口的同步请求返回 HTTP 524，该入口的异步生图接口未启用；改用系统已有的 `gpt-image-2.5` 模型及其配置地址后成功取得图片。不能仅根据域名入口的超时断言模型不可用。

安装后可在管理员视觉手册中编辑，在 Skills 文件树中查看完整包；用户在项目设置中选择后，系统按阶段读取对应文件。
