# 星穹写实 3D

写实三维电影角色，物理材质与自然人体结构，皮肤细节、毛发与硬表面装备同等精致。主色体系：珍珠白、钛灰、深海蓝与琥珀指示光。

## 风格定位
适合3D写实科幻的连续短剧资产与镜头创作。轨道空间站观景廊，地球弧面位于远景，扶手与舱门构成连贯透视线是封面场景示例，实际项目应使用剧本场景，不强行搬用封面人物与道具。

## 文件路由
全局美学读取 prefix.md；人物读取 character.md，变体再读 character-derivative.md；道具读取 prop.md，变体再读 prop-derivative.md；场景读取 scene.md，变体再读 scene-derivative.md；分镜读取 storyboard.md 和 technique-storyboard-table-design.md；视频读取 storyboard-video.md；全局光影与声音读取 technique-director-rules.md。按当前阶段读取相关文件，不把整包反复塞入提示词。

## 执行原则
仅定义画风、资产一致性与镜头视觉技法，不重写剧情、台词或系统功能契约。画幅沿用项目画幅；时长、分辨率、引用类型和数量服从本次模型能力。先保持角色身份再表达风格。输出遵守平台当前任务结构，不自创接口名或外部软件指令。

## 风格偏差检查
避免游戏低模、满屏锐化、橡胶皮肤、盔甲无重量、星空粒子穿过室内。若剧本与示例冲突，以剧本事实为准，只迁移材质、光线和绘制方法。
