# 悬疑推理

以公平线索、信息差和证据反转推进剧情，适合调查、犯罪谜案与心理悬念。

## 导演目标
让观众有机会推断真相，反转改变证据的解释，而不是临时添加答案。

## 阶段使用
- 章节分析、剧本创作与剧本审核：阅读本说明和 `director-planning.md`。
- 分镜制作、审核与修复：阅读 `storyboard-table.md`，需要核对叙事意图时按需参考规划。
- 视频提示词：仅承接已生效分镜与分镜规则，不重新改写剧情。
- 只处理当前章节与相关记忆，不预生成全部章节，不反复读取无关原文。

## 与平台协作
本手册约束叙事和调度，不指定真人、2D、3D或具体画风；外观遵从项目视觉手册。系统任务契约、用户明确要求和实际模型能力优先，类型技法按剧情取舍，不强行套固定套路。
文件生成不代表正式剧本或分镜已绑定。通过系统现有工具保存版本、关联章节和完成审核；工具不可用时报告缺失，不伪造接口、资产或完成状态。章节记忆通过独立记忆流程保存，不写入剧本正文。审核问题按平台用户决策流程处理，不自行越过待确认状态。
