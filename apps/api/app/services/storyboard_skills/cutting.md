# 切镜分寸（改编自 eternityspring/shuohao-skills，Apache-2.0，项目适配修改）

一套短剧镜头好不好看，一半在切得准不准。下面是可以在分镜阶段直接落实的判断方法。
本文件给的是分寸和建议，不是独立秒数门；镜头时长仍必须取自平台注入的合法档位。

## 节奏

- 三秒左右一切是短剧的呼吸：竖屏观众的注意力就在这个粒度。切太快信息接不上，切太慢人就走。
  节奏带应该深浅相间、长短相间，不能整场都是同一个景别的三秒中景。
  **这条说的是剪辑颗粒度，不是镜头时长档位。** 绝对不要把「三秒」理解成默认取模型最短档：
  镜头时长必须按内容需要从平台给的合法档位里选，内容需要 10 秒就写 10 秒，
  内容只有一次瞬间反应才写短档。若模型的合法档位里没有三秒，就按其短、中、长档表达同一节奏。
- 对话切正反打：问话给问话人近景，答话切答话人近景，来回跳。谁的台词信息量大，谁的脸给得更近。
  能在同一段里解决的对话，不要拆成多段生成。
- 反应镜头是免费的戏。一句重台词之后切听者的脸两三秒，不用写词；画外音盖空镜或特写，天然省口型。
- 关键动作独立成切。「她一把按住箱盖」这种动作值得单独一格短特写插入，它是节奏的重音。
- 段的最后一切留钩：段尾镜头要么是悬念的具象（口袋、铜扣、灯），要么是下一段的引子。

## 进场与定场

- 每集或每场的第一切要给运动中的主体（跟拍中奔跑、固定机位里的人在动）。静物特写开场是死画面，
  留给第二个落点。
- 新空间用三件套交代：运动主体 → 大远景定场 → 关键局部特写。让观众在几秒内知道谁在动、在哪、看什么。

## 衔接

- 动接动：上一镜结尾的动势（手伸向箱子）接下一镜开头的动势（手被按住）。切点选在动作中间，
  不要等动作做完再切。
- 超短片段之间的跳感来自位置和动作不连续，不是时长不够。改写时先读前后两镜，确认人物位置、
  朝向、持物、伤势和运动方向能接上，再动其中一镜。
- 空间变化要有过程。上一镜在岸路跑、下一镜直接站在栈桥上，中间缺了走过去的那一拍。

## 运镜

- 固定镜头是默认。推给情绪、拉给收场、跟给移动；一个段里超过两种运镜就该自问是不是在炫技。
- 高速位移时摄影机同步追随交锋中心，锁定构图不等于固定摄影机；但明确要求固定机位时不得追拍。
- 运镜有一个主要动机。无法同时实现的两种运动拆开，不要在同一镜里既环绕又急推又升降。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 舞台剧病 | 一段到底杵在一个机位 | 对话切正反打，动作给插入特写 |
| 均匀病 | 每切都是同样时长的中景 | 深浅相间、长短相间才是节奏 |
| 秒数漂移 | 改了镜头秒数，提示词或切点没跟着改 | 秒数是下单不是估算，改一处必须同步改另一处 |
| 台词爆仓 | 台词念不完却给了短镜头 | 加时长或拆切，不能让台词挤在镜头外 |
| 声景漏改 | 画面动作改了，声音描写还是旧动作 | 声景也是动作指令，画面、描述、声音三处一起改 |
| 特写失忆 | 大特写里的道具和设定图长得不一样 | 挂道具设定图当参考，提示词点出锚点特征 |
| 换景不换组 | 同一组里从栈桥切进船舱 | 换景开新组，一组一个环境锚 |
| 改切不读邻切 | 只改了一镜，邻镜还停留在旧位置 | 改任何一镜连读前后两镜，位置是连续状态 |
| 广播剧 | 整场只有台词 | 每两三句台词之间插一拍画面动作 |
| 注水 | 寒暄、让茶、无意义过场占了半集 | 删。每一拍要么推进剧情要么翻转关系 |
| 演讲癖 | 一个人连说四句 | 拆给对手，或用动作打断 |

## 边界

- 本文件不改变剧本事实、台词原文和胜负结果，只决定怎么拍。
- 明确静止、定格、一镜到底的要求优先于本文的动感与运镜建议。
- 与平台注入的模型时长档位冲突时，按合法档位重新表达节奏，不照抄本文出现的秒数示例。
