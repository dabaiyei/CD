# H3 提示词补充（改编自 eternityspring/shuohao-skills，Apache-2.0，项目适配修改）

本文只补项目 H3 专用协议（`video-prompt-generation-h3.md`）**尚未写明**的几条写法经验。
模式映射、对齐指令原文、三段式与六段式字段、`<Audio N>` 规则、`audio_enabled_for_this_task`
开关和 JSON 输出契约以那份协议为准，本文不得覆盖、改写或与之并行发明第二套写法。

## 语言分工

- 主体描述、字段名、镜头标记使用英文；三样东西保留原文语言：**台词**（`<d>[Chinese] …</d>`
  逐字原文，一个标点都不许动）、歌词、画面里可见的文字（用英文双引号原样引用，不翻译）。
- 台词的语言标签和正文只在 `<d>` 内。身份、年龄段、音色、语速和语气写在 `<d>` 外面。
- 画外音用官方句式 `says in an off-screen voiceover … while their lips remain completely closed`，
  并明确画面人物嘴唇保持闭合。

## 每个镜头的运镜词必须落在自己那一行

- 运镜词表是 H3 官方词（`static shot`、`push in`、`pull out`、`pan left/right`、`tilt up/down`、
  `tracking shot`、`arc shot`、`crane shot`、`handheld`、`dolly zoom` 等），可加幅度与速度，
  写成自然英文动作句，例如 `a slow push in toward the white-knuckled hand`。
- 第 k 个 `[Shot k]` 的运镜词必须出现在它自己那一行里，不能只在首行或总述里提一次。
- `At 00:0X.XXX,` 的切点时刻等于前面各镜头秒数的累计，改了任何一个镜头秒数就要同步改这里。

## 关键帧怎么用

- 主分镜图（f1）钉在 0.00 秒，是这一段世界观的完全参照。
- 每个 `[Shot k]` 先锚定 `<Picture k>` 的构图与人物**此刻的位置状态**，再写动作怎么展开。
- 图和文对不上时模型听图的，所以文字只补图里没有的信息：构图、位置状态、姿态、动作路径。
  不要在文字里重新描述设定图已经定死的长相和材质。
- 首帧约束身份与开场空间，不冻结全程姿势；`fully_preserved` 不能和指定的动作要求自相矛盾。

## 声音字段的分工（踩过的坑）

- 台词、歌声、剧内可见的声源 → 描述字段；环境声与物理动作声 → `overall_soundscape`；
  角色听不见的配乐 → `non_diegetic_music`。
- `overall_soundscape` 只写环境与动作声，**不复述台词内容**。
- **声景也是动作指令**：声景里写「铜铃在撞击时炸响」，视频会真的把撞击演出来。画面动作一改，
  描述、声景和中文对照三处必须一起改，只改一处会得到自相矛盾的成片。
- 换场、换景或动作性质变化时，声景跟着换；整段只有一种环境声，说明没跟着画面走。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 声景漏改 | 画面改成搭手卸担，环境音还写着铜铃撞击 | 三处一起改 |
| 秒数漂移 | 改了镜头秒数，对齐指令或切点时刻没跟着改 | 逐字对账，改一处必改全部 |
| 台词爆仓 | 台词念不完却给了很短的镜头 | 加时长或拆切 |
| 特写失忆 | 大特写里的道具和设定图长得不一样 | 挂道具设定图并点出锚点特征 |
| 假切镜 | 只是轻微角度变化却写了 `the camera cuts to` | 轻微变化用自然运镜，真实切镜才写切 |
| 表演塌陷 | 只列起止姿势或每秒换一个动作 | 写连续的路径、接触反馈和自然收势 |
| 慢镜扩散 | 整段都在慢放 | 只有大招蓄势、显形和关键命中短暂放慢，然后明确回到实时 |

## 边界

- H3 单次目标时长、分辨率、画幅、生成模式、参考媒体数量和格式一律服从平台本次执行契约，
  本文不写死任何范围。
- `audio_enabled_for_this_task` 为 `false` 时，两个声音字段严格写 `N/A`。
- 本文不新增负向段；`negative_prompt` 的取值按项目协议处理。
