# 参考图纪律（改编自 eternityspring/shuohao-skills，Apache-2.0，项目适配修改）

分镜图的质量一半在提示词，一半在挂对了参考图。本文件与项目已有的首帧空间设计硬约束并用；
出现冲突时，平台的 `reference_map`、参考媒体数量上限和 `frame_layout` 契约优先。

## 挂图按「画面里有什么」，不按「这场属于哪个场景」

- 场景设定图（该场当前光照状态）必挂，它是环境、材质和光的唯一标准。
- 画内每个角色的设定图有几个挂几个。
- 画内叙事道具的设定图有就挂。
- **会入画的大资产也要挂它自己的设定图**：船、车、宅门、大型坐骑。不挂就每帧发明一个新的。

同一场戏里画面出现了别处的东西，就挂那个东西的设定图，不要因为「本场是栈桥场」而漏掉船。

## 位置状态是连续剧情状态

- 提示词要写明人物**此刻**的位置状态：已经上船、在舱内、站在桥头。只写构图不写状态，
  模型会把已经上船的人又画回岸上。
- 位置只在有走过去的那一拍时才改变。改任何一镜都要连读前后两镜，位置、朝向和持物不能跳。

## 图与文冲突时模型听图的

- 提示词专心写构图、此刻的位置状态和姿态。长相、材质、服装细节交给参考图，
  不要用大段文字重新描述已经在设定图里定死的五官。
- 身份参考图只锁定外观，不要连它的四视图版式、白底和端正站姿一起搬进镜头。
- 招式图只锁定特效、武器和召唤物外观，不提前施放，也不从招式图决定人物性别与站位。

## 链式参考

- 某角色还没有设定图时，先出他看得最清的那一格，之后所有带他的镜头都拿那一格当身份参考。
  同一场里同一张脸不许换人。
- 同一场的首格成图值得一直挂着，用来锁定世界观和空气密度。

## 出图后先扫一眼

- 和场景设定图是不是同一个世界（材质、光、旧化程度）。
- 角色的脸和衣服对不对得上设定图。
- 景别对不对：写着特写出来却是全景，重生成。
- 有没有多出来的人：背景围观群众是最常见的污染。

## 边界

- 只使用平台列出的可用资产，不虚构文件路径，也不在提示词里宣称已经上传。
- 实际提交给模型的图片顺序以 `reference_map` 为准，提示词引用必须与之一致。
