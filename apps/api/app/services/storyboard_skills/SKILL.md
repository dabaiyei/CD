# 分镜方法：项目适配版

分镜与 H3 提示词方法学自 eternityspring/shuohao-skills（作者烁皓），源提交
7ebef4f2f53159ee1eaaec2793271a114a8be8cc，Apache-2.0，原许可证见同目录 LICENSE。
上游是面向 Claude Code / codex 的独立 skill 集合（novel-outline、novel-characters、novel-art、
novel-script、novel-storyboard 五段管线，自带 Node 脚本与质量门）。本项目只吸收其中与
**分镜阶段**直接相关的方法论，并改写成本项目的术语、结构与硬约束；没有移植上游的 Node 脚本、
报告渲染器、示例数据或目录约定。

吸收范围与落点：

| 上游内容 | 本项目落点 | 处理方式 |
| --- | --- | --- |
| 切镜分寸、正反打、动接动、进场三件套、段的收尾留钩 | `cutting.md` | 改写为分镜阶段建议，不设独立秒数硬门 |
| 参考图纪律、时刻位置状态、大资产挂图、链式参考 | `reference-images.md` | 与项目首帧/资产引用契约合并表述 |
| H3 语言分工、声景也是动作指令、画外音句式、运镜词入本行 | `h3-prompt.md` 与 `video-prompt-generation-h3.md` | 只补本项目协议缺失项，不重复既有模式映射 |
| 常见病表、节奏均匀病、台词爆仓、秒数漂移 | `quality-gates.md` 与 `storyboard_quality.py` | 表内条目供模型自查，可机械判定项落成程序门 |
| 每拍认领、节拍不重不漏 | 见 `quality-gates.md`「覆盖对账」 | 与本项目已有的场景分段覆盖检查对齐 |

**没有吸收**：上游的 `params.maxSegmentSeconds` 段/分镜两层 schema、`beats:[起,止]` 字段、
`promptLang` 开关、质量门失败累积文件（`.gates.jsonl`）。这些都需要改动本项目分镜数据结构或
落盘约定，收益不足以抵掉兼容风险；本项目继续使用现有 `StoryboardShot` 结构与场景分段覆盖机制。

## 调用边界

只由分镜生成、分镜审核、分镜修复和视频提示词阶段按需检索，不进入普通对话、剧本生成或资产提取。
检索按阶段与镜头内容选择文件，不整包塞进提示词。

## 优先级

- 平台注入的模型能力、合法时长列表、参考媒体数量与格式、输出结构是最高优先级硬约束。
- 本方法的固定秒数、节奏建议与之冲突时，映射到当前模型的合法档位，不得照抄秒数。
- 明确要求静止、固定机位或一镜到底时，本方法的运镜与动感建议让位。
- 战斗专项规则对招式、连续攻防和大招表现优先于本方法；画风与人物外观仍按项目设定。
- 本方法只给分镜与提示词技法，不改剧本事实、台词原文、资产归属与胜负结果。
