# 分镜质量门（改编自 eternityspring/shuohao-skills，Apache-2.0，项目适配修改）

上游把质量门写成脚本确定性检查，不靠模型自觉。本项目沿用这个思路，但只把**能机械判定**且
不会误伤正常分镜的条目落成 `storyboard_quality.py`，其余列在下面供生成与审核阶段自查。

## 程序检查（平台执行，作为审核意见出现）

| 检查 | 判据 | 说明 |
| --- | --- | --- |
| 台词装得下 | 该镜台词的折算秒数相对镜头时长的比例超过提示线 | 按每分钟语速折算，标点也占时间；画面字幕不计入台词。超线提示加时长或拆镜 |
| 不集中在最短档 | 同一批镜头过多落在同一个时长 | 明显的均匀病与偷懒取整 |

两条都是**提示**，不自动否决分镜，也不擅自改写剧本事实、台词原文和胜负结果。

**为什么不再多落几条**：本项目一条分镜记录是一段提交给视频模型的完整视频，内部可以包含多个
剪辑分镜，所以「一个镜头一个运镜」「静止镜头不得有运镜」这类按句子判定的规则在真实数据上
大面积误报，已经撤掉，改回由生成与审核阶段按语义判断。时长合法性、资产引用、首帧冲突等
已有程序检查保持原样，不在本文件重复。

## 覆盖对账（模型自查）

- 剧本的每个场次都要有镜头认领，不能只覆盖前几场就收工（项目已按场景分段生成并逐一校验）。
- 每场的行动、关键信息和台词按顺序被覆盖，不能新增输入里没有的剧情。
- 相邻镜头通过动作方向、视线、构图、声音或空间锚点衔接。

## 节奏自查

- 景别与时长有变化，不是整场同一个景别的同一个秒数。
- 对话切正反打，重台词后给反应镜头。
- 关键动作有独立的一格，而不是挤在长镜头的描述里一笔带过。
- 段尾留钩，段与段之间是剪辑点。

## 连续性自查

- 人物站位、朝向、服装、伤势、道具持有和场景状态在相邻镜头间连续。
- 位置只在有过程的那一拍改变。
- 主光世界方向与色温连续，换机位不让光源跟着相机转。
- 台词原文与说话人保留，不翻译、不改写、不增加无来源台词。

## 可执行性自查

- 描述的是可拍摄的动作、环境动态和运镜，不是「悲伤地看着」「气氛紧张」这类抽象心理。
- 画面里出现的大资产有对应参考图。
- 战斗镜头只规划时间轴、实力关系、结果与进出状态；详细逐招由视频阶段的战斗模块展开，
  不因缺少细招而判不合格。

## 边界

- 门的固定秒数示例必须映射到当前模型的合法档位，不得照抄。
- 用户明确确认的取舍优先于本文件的建议。
- 门失败只定位问题与最小修复范围，不代替用户做删改决定。
