# 招式、宝术与神通（项目适配修改，来源见 SKILL.md）

读取当前人物绑定的招式记忆和无人特效参考图，明确招式归属、释放点、朝向、目标和尺度。参考图只有特效/武器/召唤物，不能据此重新造一个人物。
效果必须有传播方向：从掌心前推、沿剑锋延伸、从法印升起或向接触点汇聚；不要所有技能都变成环绕人物的光圈。手印须有清晰手势变化和发力时机，不因设计手印拖慢整段战斗。
常规术法融入实时拆招：护盾偏折后顺势换线、法器回收牵引后再追击，反应和环境反馈与轨迹一致。不得新增招式目录之外的命名神通来改变胜负。
大招才突出特写、显形、尺度递进、峰值冲击和余波；碾压一次击破，不重复命中来凑时长。未完成的蓄势或光效在下一镜持续，已消散或损毁的物体不能复原。
