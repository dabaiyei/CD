# 徒手与短距离连攻（项目适配修改，来源见 SKILL.md）

根据人物已有体系选择：咏春强调中线、桥手、拍挡接拳和转马；八极强调进身、肩胯肘的短促发力；拳击强调组合拳、滑步摇闪；腿法须有支撑脚与髋部转动。不把不同流派名机械堆在一起。
一组连续攻防由试探逼反应、改变攻击线、拆招、反击再压制组成，攻击和应对写在同一动作条目。局部近身可每秒2—4次接触，串成长短变化的爆发簇，不每拳重新站稳摆姿势。
例如拍开来拳借肘线切入，对方转胯避让反顶，进攻者顺回弹侧移接低位攻击；这是因果语法，不照搬固定连招。改变高低线与重心要符合距离、服装和体能，不能无理由每招腾空。
连消带打体现双方主动应变。仅反复写“高速出拳、对手格挡”不算详细编排；每次接触留下具体方位、失衡或压力变化。
