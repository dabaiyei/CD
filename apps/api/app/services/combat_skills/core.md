# 电影武指核心（改编自 CY-CHENYUE/martial-arts-director-cy，Apache-2.0，项目适配修改）

清晰、空间几何、动机、风险、编排、受压反应和后果共同构成动作戏。每条动作写出人物＋具体轨迹＋对手反应＋接触结果，并让前招余势带出后招，避免孤立姿势列表和抽象“激战”。
使用已给人物、服装、武器与招式；表情和动作体现其处境，但不能另写台词或改变剧情胜负。持物、损坏、衣饰、光向和站位持续演变，不在节拍之间复原。
势均力敌以高速实时连攻、变线、拆招和反击为主，局部每秒2—4次接触；完整摔投和大位移不强行挤成一瞬。强弱悬殊只在决胜瞬间破防，其他时间体现技能效果与后果。
每一镜承接已有进出状态，战斗中途不重新起势、抱拳、试探或仪式性收势。大招/关键命中才允许短暂慢镜；明确静止要求保持静止。
方法服务于当前模型支持的时长、媒体与既定切点。只写本镜完整动作时间轴，不生成海报、不假设参考图是多宫格、不固定15秒，不为字数目标删掉动作。

## 本项目补充：动作与能力的可执行性

有效攻防必须改变距离、主动权、受击目标、武器控制或招式阶段；镜头切换、发光、粒子增加不算出招。密集接触嵌入连续的少量因果链，不把每个火花都拆成独立攻击。
逐拍核对持械手、空闲肢体、支撑点、落点和可达距离；握剑的手不能同时撑地，腾空后不能无支点再蹬地。高速动作越复杂，摄影轨迹越简单，避免双方瞬移及靠切镜补动作。
已有能力按“前提→发动→作用→结束”展开。只允许使用项目已经定义的身体、装备和能源；奔跑本身不等于拥有蓄能术，普通格挡不凭空升级为法术。不能为了使用参考方法给角色新增能力。
终结动作使用本段或前镜已经建立的机会，保持已确定的胜负；不得强加逆转或突然提升实力。末态交代位置、朝向、持械、支撑与持续伤损，供下一镜接续；明确静止的结尾仍须静止。
