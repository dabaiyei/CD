# 动作与摄影协同（项目适配修改，来源见 SKILL.md）

清晰度优先：每个节拍可辨认攻击方、目标、接触点和反应。中全景交代双方及环境纵深，中近景跟随交锋中心；特写只在既定机位允许且不遮断攻防因果时使用。
高速位移时相机同步追踪主体或双方交锋中心，写明运动方向、速度和距离，避免人物跑出画面后相机才追。保留前景掠过、中景人物、背景位移的层次；运动模糊用于边缘，不能把武器和接触点抹掉。
轴线与地标固定，换侧须有可见绕行或既定切点。不能每招自动切镜、突然360度环绕；用户要求固定机位则保持锁定，靠人物调度体现速度。
前招重心、落脚、持械手和发力余势连接下一招。主光方向稳定，金属碰撞或法术光仅在接触/释放处短促照明，亮度变化有起因、持续和消退，不全屏闪白掩盖动作。
衣袂、尘土、水花或碎屑沿实际受力方向运动；环境效果体现重量，不能凭空增加场地、家具、天气或声音。
