# 电影武指：项目适配版

基础武指方法改编自 CY-CHENYUE/martial-arts-director-cy，源提交 65c7c1dd35fcf4a01bfc1372ab506b60e2d0d26d，Apache-2.0，原许可证见 LICENSE。
场景路由与补充方法另参考 qualsenWeb/fight-video-create-skill（提交 f0626a01d32a476c4e827b3fa1aba6dcdf571ead）的分层检索、动作可行性和条件对抗思路，由本项目独立编写；没有复制该仓库正文或脚本，前述 Apache 来源说明不表示其仓库采用相同许可证。

## 调用边界

只由 combat_choreography 在最终视频打斗编排时使用。普通对话、剧本、分镜不加载本文及参考正文；剧本和分镜只提供时间轴、实力关系、结果与 martial_systems 分类。平台先匹配目录说明，再读取命中的参考文件。

## 生产约束

每个动作明确谁、如何发力、武器或肢体轨迹、对手即时反应、引出的下一动作。沿用人物图与招式图的身份、归属和外观；没有的武器、人物、法术不可为了炫酷凭空增加。
前招余势带出后招；位置、距离、持物、伤损连续，不能用跳剪掩盖复位。环境互动只使用本场已存在物体。高密度也必须看清攻防因果。
详细动作只在最终视频阶段展开，由程序按秒编译，禁止为了字数限制删去动作。总时长、参考图数量、格式、音频和语言均以当前模型契约为准。
势均力敌以高速连续拆招为主；碾压一次决胜，表现技能尺度和后果。仅大招展示或明确要求使用慢镜；已经在打的片段不重新抱拳、试探、起势或重复收势。
默认使用项目人物与真实前镜尾帧。此适配版不创建多宫格海报、白模、独立人物首帧，也不写不存在的格序或图片编号协议。不会更换项目画风、角色或固定为15秒。

## 资源目录（按需读取）

- camera.md：同步跟拍、景别、轴线、惯性、环境光与局部特效。
- close-quarters.md：徒手短促连攻、桥手、肘膝、爆发与实际反应。
- grappling.md：贴身控制、重心破坏、摔投与地面衔接。
- sword.md：剑刀的连续变线、格挡回弹、长短兵器接触。
- polearm.md：枪棍的距离管理、拦拿扎扫及近身转换。
- flexible.md：软兵器的甩出、缠绕、张力、回收路径。
- spell.md：神通招式的归属、释放点、方向、尺度与特效反馈。
- giant.md：巨物与小体型人物的速度、尺度、空间和追踪关系。
- chase.md：高速移动、地形互动与连续交锋。
- restricted-space.md：现有受限地形的支撑、路线与持续破坏。
- multi-opponent.md：多方向重叠威胁，避免排队攻击。
- asymmetric.md：优势距离、累积破绽与既定结果；纯碾压不加载。

场景方法只依据当前镜头和战斗窗口匹配，最多两份；不因背景资产提到某种场景就加载。对峙窗口不加载攻击与场景方法。无匹配只用通用核心与摄影规则，不假装命中特定技能。所有参考合计仍不超过4800字符，任何新增方法均参与内容哈希与缓存失效。

这些是方法词典，不是固定套路；按人物、服装、地形、实力差和已确定结果设计，不强行满足姿态配额。
