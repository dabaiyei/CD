# 表演核心：表情不是一个词，而是一段表演

“女主很伤心”是无效写法。把眼神、眉毛、嘴角、身体反应、剧情状态说清楚才是有效写法。

## 万能表情公式

任何情绪都拆成五个部分，缺一个表情就“没戏”：

1. 眼神：看向哪里？躲闪/发亮/失焦/盯住？例：眼神从克制转为震惊，瞳孔微微放大。
2. 眉毛：放松/上扬/压低/皱起？例：眉头慢慢舒展。
3. 嘴角和嘴唇：抿住/颤抖/张开/压住笑？例：嘴唇微张但没有说话。
4. 身体反应：后退/前倾/攥紧手/肩膀放下？例：手指慢慢攥紧。
5. 剧情状态：此刻刚发生了什么？例：刚听到真相 / 被背叛 / 终于释然。

最后补一个“像……”的比喻句点明表演意图，帮模型理解这场戏在演什么。

## 创造新表情的步骤

1. 先用一句话说出情绪的本质（不是“悲伤”，而是“信念被击碎后的空”）。
2. 按公式逐项描写：眼神 → 眉毛 → 嘴唇 → 身体反应，每一项都指向这个本质。
3. 补“像……”的比喻句收尾。
4. 强度分层：同一种情绪至少想出轻微/中等/极致三档。
5. 自查：这条提示词里有没有身体反应？只有脸没有身体的表情不合格。

## 新表情写法模板

```
[情绪名]：[眼神描写]，[眉毛描写]，[嘴角/嘴唇描写]，[身体反应]，像[表演意图比喻]。
```

示例（库外自创“听到噩耗后的职业性冷静”）：
> 眼神在听到关键词的瞬间定住，眉头没有动，嘴唇缓慢地抿成一条线，
> 握着杯子的手指指节泛白却保持坐姿端正，像多年的训练替他挡下了这一击。

## 强度分层

同一种情绪至少想三档：轻微 → 中等 → 极致。例如悲伤 = 隐忍难过 → 无声落泪 → 崩溃大哭。
默认用中等档；只有剧情明确要求爆发时才用极致档，避免一上来就嚎啕。

## 镜头组装结构

[角色设定] + [表情提示词] + [场景情绪] + [镜头景别] + [光影风格]

- 表情戏优先近景或面部特写，远景看不清情绪；但不得为了表情擅自改分镜已经确定的景别与机位。
- 一场戏的情绪要有递进，不要突然爆炸，也不要一个镜头里从平静直接跳到崩溃。
- 不堆砌“极度、强烈、震撼”，情绪太满反而没有层次。

## 三条避坑

1. 一条镜头只选一种主情绪，不要又开心又愤怒又害怕。
2. 不能只写脸。手、肩膀、呼吸、后退半步往往比脸更真实，必须有身体反应。
3. 失败时先诊断原因（角色图问题/表情词问题/镜头距离问题/场景情绪问题），不要盲目重抽。

## 与声音和台词的关系

表情描写服从本镜音频开关。音频关闭时，“嘴唇保持完全闭合”，不得出现张口说话、喊叫、
呐喊或任何可发声的口型；情绪只通过眼神、呼吸、眉眼、肩颈和手部表达。
音频开启时，口型只能对应已锁定的台词，不得为表情新增台词或发声。
