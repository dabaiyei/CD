# 表演方法：项目适配版

来源：项目内置 `skills/ai-drama-expressions`（AI 漫剧人物表情提示词库），由本项目改写为
视频阶段的独立表演模块。原库的 60 条固定表情、万能表情公式、镜头组装结构和避坑清单被
拆分为可检索文件；没有引入外部依赖或运行时访问。

## 调用边界

只由 `expression_choreography` 在最终视频提示词阶段按需读取。剧本与分镜阶段只登记情绪
时间轴（谁、在几秒到几秒、什么主情绪、什么强度），不展开五要素表演；也不加载表情正文。
平台先按情绪名与关键词路由，只打开命中的类别文件。

## 与其它规则的关系

平台注入的模型能力、合法时长、参考媒体、对白锁定与输出结构是最高优先级硬约束。
本方法不新增台词、不改变剧情结果、不改变画风与人物外观，只把已经确定的情绪转译为
可拍摄的面部与身体表演。战斗专项规则对招式、连招密度与大招表现优先于本方法；
战斗中的表情只负责情绪层次与打击反馈，不削弱动作密度。

## 资源目录（按需读取）

- core.md：万能表情公式、镜头组装结构、强度分层与三条避坑。始终加载。
- emotion-basic.md：基础微表情（平静克制、欲言又止、暗自判断等）。
- emotion-joy.md：开心和松弛（浅浅开心、喜极而泣、久别重逢等）。
- emotion-fear.md：紧张和恐惧（突然警觉、发现真相、大脑空白等）。
- emotion-grief.md：悲伤和崩溃（隐忍难过、无声落泪、崩溃大哭等）。
- emotion-anger.md：愤怒和对抗（忍着怒气、冷笑反击、含泪愤怒等）。
- emotion-complex.md：复杂情绪与戏剧转折（笑里藏刀、强颜欢笑、下定决心等）。

这些是表演词典，不是固定套路；同一种情绪至少分三档强度，默认使用中等档，
只有剧情明确要求爆发时才升到极致档。
