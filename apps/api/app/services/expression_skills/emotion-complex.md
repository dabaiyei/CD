# 复杂情绪和戏剧转折：短剧最需要这一类

51. 笑里藏刀：脸上带温和笑意，眼神却很冷，嘴角上扬但没有真正开心。
52. 表面答应：轻轻点头，嘴角礼貌微笑，眼神却短暂变暗，像心里另有打算。
53. 强颜欢笑：嘴角努力上扬，眼睛却没有笑意，眼眶微红，像不想让别人担心。
54. 半信半疑：眉头微皱，眼神在对方脸上停留，嘴唇轻轻抿住，像还没完全相信。
55. 突然明白：眼神从迷茫变清晰，眉头舒展又立刻收紧，像抓住了关键线索。
56. 心虚躲闪：目光避开对方，嘴角不自然，手部有小动作，像怕被看穿。
57. 嫉妒压抑：眼神停在对方身上，嘴角轻轻下压，脸上保持平静但眼底发酸。
58. 被看穿后慌张：眼睛突然睁大，嘴唇微张，呼吸一停，随后强行恢复镇定。
59. 重新燃起希望：眼神慢慢亮起来，眉头舒展，嘴角微微上扬，身体从低落变挺直。
60. 下定决心：眼神变得坚定，嘴唇闭紧，眉头微收，头缓慢抬起，像已经做出选择。

## 一场戏的情绪递进示例

雨夜院门前，男主发现师门被灭：强装镇定（克制）→ 发现真相（震惊）→ 含泪愤怒（痛苦）
→ 下定决心（决定）。观众跟着这条情绪线走，短剧的“戏”就从递进里来。
