# 基础微表情：先让人物不像木头人

1. 平静克制：眼神稳定，眉头放松，嘴唇自然闭合，脸上没有明显笑意，像把情绪压在心里。
2. 轻微疑惑：眉头轻轻皱起，眼睛微微眯起，嘴唇略微张开，像刚听到一句不确定的话。
3. 认真倾听：目光集中看向对方，脸部放松，身体微微前倾，像在捕捉每一个细节。
4. 若有所思：视线稍微偏向一侧，眉眼安静，嘴角收住，像在心里快速推演答案。
5. 欲言又止：嘴唇微微张开又停住，眼神闪烁，喉结轻动，像有话不敢说出口。
6. 强装镇定：脸上保持平静，眼底却有细微紧张，手指轻轻收紧，像在努力不暴露情绪。
7. 礼貌微笑：嘴角轻轻上扬，眼神温和但不过分热情，适合初次见面或表面客气的场景。
8. 尴尬停顿：笑容僵在脸上，眼神短暂躲闪，嘴角不自然地抬起，像不知道怎么接话。
9. 不动声色：面部几乎没有变化，眼神却冷静观察对方，适合隐藏真实目的的人物。
10. 暗自判断：眼睛快速扫过对方表情，眉头微收，嘴角压低，像已经发现了问题。
