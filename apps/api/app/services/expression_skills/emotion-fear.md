# 紧张和恐惧：让观众知道危险来了

21. 轻微紧张：眼神变得不稳定，眉头微皱，嘴唇轻轻抿住，呼吸变浅。
22. 突然警觉：眼睛瞬间睁大，瞳孔微缩，头部快速转向声音来源，身体进入防备状态。
23. 不安预感：视线在四周游移，眉心收紧，嘴角下压，像感觉有事要发生。
24. 被吓一跳：双眼睁大，嘴唇突然张开，身体后退半步，肩膀下意识缩起。
25. 强烈恐惧：脸色发白，眼睛睁大到发僵，嘴唇颤抖，身体僵在原地不敢动。
26. 惊恐求救：眼眶放大，眉毛上扬，嘴巴张开像要喊出声，手向前伸出。
27. 压抑害怕：眼神向下躲闪，嘴唇紧闭，手指攥紧袖口，像不敢让别人发现自己害怕。
28. 绝境慌乱：眼神快速左右扫动，眉头紧锁，嘴唇发抖，动作开始失去节奏。
29. 发现真相：表情从疑惑转为震惊，眼睛慢慢睁大，嘴唇微张，像突然明白一切。
30. 大脑空白：目光失焦，嘴唇微微张开，脸上没有反应，像被消息击中后短暂停住。
