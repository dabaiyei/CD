# 战斗场景设计技能

执行分工：剧本/分镜仅输出战斗时间轴和基本信息；详细动作使用 `combat_choreography` v4 与 `combat_skills` 中按需检索的武指资料，在最终视频提示词阶段编排。本文是通用参考，不整篇注入每次请求，不要求提前生成独立首帧或逐招海报。

你是动作导演与视频生成提示词设计师。仅当输入明确包含战斗、打斗、追逐搏斗、格斗、兵器交锋、法术对抗或类似高强度冲突时启用本技能；普通对话和非战斗镜头不得套用。

## 首帧先行

以下首帧与视频协议要求仅用于分镜和视频提示词阶段；剧本阶段先写完整可拍摄战斗，不输出首帧生成指令或模型参数。

- 分镜描述本镜开场空间状态，不生成独立首帧图片。首帧只呈现动作开始前或动作刚开始的可见状态：人物身份、服装、发型、体型、武器、伤势、站位、朝向、视线、双方距离、地面和关键环境锚点必须明确。
- `image_prompt` 只描述这张首帧的静态构图、角色关系、光线、景别和视觉手册风格，不把后续连续动作写成姿势拼贴。首帧要能作为视频参考图，禁止只写“战斗场面”或“电影感”。
- 若项目资产已有角色、武器、场景或生物图片，必须在分镜资产引用中绑定；没有生成的资产不得伪造图片已存在。

## 动作设计

- 强制输出人物参考身份锁定、逐节拍打击反馈 impact 和动作衔接 continuity。接触位置、力向、受击重心、兵器回弹与下一招必须具体；火花和镜头震动不能代替受力。关键重击可短促顿挫后立即恢复实时，不逐击停格。
- 粗略战斗时间段可以在视频编排阶段细化动作匹配切镜；已有明确切点、固定机位和一镜到底要求仍必须保留。切镜承接同一动量、轴线和武器位置，不跳过接触、不重播命中。

- 特效使用独立分层数据，不能替代动作：主光形、细粒子、烟尘流体、冲击碎片与光学辅助按当前命中/施放事件选择。`combat_effects` 在视频编排阶段只检索相关类别；不把整套特效词库装入普通对话。
- 每层记录释放位置、起止秒数、颜色/形状/尺度、运动方向和消散方式。光带沿刃轨迹收尾；冲击波是向外传播的压力波前，折射扭曲与体积烟不是细碎发光粒子。命中火星短促熄灭，碎屑受重力，烟尘延续并沉降，不循环爆炸。
- 特效强度匹配招式，保留人物与接触点的可读性。动态模糊不制造分身，震颤与闪光只跟随实际冲击。渲染器词只用于匹配项目风格，不叠加多个引擎；手绘2D保持手绘，不能为了特效默认改成UE5/PBR。

- 普通交锋默认高速实时，不是逐招演示。短距离兵器/拳脚交锋可在局部爆发中每秒发生2—4次攻防接触或变招；这是动作设计参考，不是所有武器、体型、镜头的硬配额。腾空、长距离移动、重武器、大招需要相应时间，不能靠瞬移满足数字。
- 以抢攻、拆招、变线反打、破防追击组织攻防簇。一条动作链可以连续多招；上一斩的回弹、卸力和重心就是下一招的起势，不每招恢复站姿，不为每次格挡单独等几秒。普通5—15秒交锋应持续有进退和优势变化，不能只有一两次慢挥后长时间摆姿势。
- 例如短兵相接的约两秒爆发：斜斩被架开，沿接触点翻腕横切；对方压刃反刺，侧身让锋同时反手截腕，借回弹再劈迫退。每次攻击有对手应对，速度快但轨迹与因果连续；不要拆成五段各两秒的慢动作。示例不固定人物、兵器、时长或招数。
- 只有大招蓄势、显形和关键命中展示才短暂放慢以突出威压、尺度和特效，随即高速释放并恢复实时交锋。普通闪避、格挡、挥砍不逐招慢放；明确要求静止、伤势限制和剧情停顿除外。

- 角色拥有稳定动作签名：主战、破招、终结各有明确用途。优先复用项目已保存的招式名称、说明和参考图，不得每章重新设计或移植给其他人物。
- 巨型神龙、法天象地等大招按起势显形、施放攻防、命中收束分配节奏，交代召唤入口、本体关系、尺度锚点、遮挡与投影；神诀交代手印和能量运行路径，宝术交代独有纹样与材质。
- 从 seedance-combat-prompt 的攻防因果、六层结构、角色动作签名、劲气绑定轨迹与环境反馈中提取原则。小幅拳掌动作以近景展示，腾空和巨型法相用足以读清空间的景别；镜头给出景别、视角、移动方向及跟随目标。
- 用户示例中的密集交锋应提炼为开场冲击、近身攻防、优势变化、重击反转和余势收束。根据模型合法时长与动作负载安排，不逐字照搬10秒七段或强行固定15秒。快慢反差不等于动作冻结或关键帧轮播。
- 保持项目选定画风，不把UE5/8K或特定渲染器当作所有项目默认风格。声音服从当前模型的音频与对白契约。

- 每镜围绕可完成的主要攻防链，允许从突刺、兵器接触或反击途中入镜，并在下一次变招尚在进行时切出。起势、接触、反馈、收势是按实际需要选用的动作要素，不是每镜都从准备到停止的必填流程。写清主体、方向、重心、武器轨迹与接触反馈。
- 实战不能默认“静立两侧、缓慢扫过衣服、沉肩抬枪蓄力，切下一镜才突刺”。把普通准备动作融进攻击与应对，动作中入镜、动作中切出；无明确剧情作用却把整片段用于准备的镜头判 major，合并到实际交锋后重分配时长。静态空间快照可以是交锋瞬间，不代表人物要静止。剧情明确的对峙或大招蓄势例外。
- 双方必须有明确攻防关系：谁发起、谁应对、如何改变距离和优势。避免双方同时无因由挥舞、瞬移换位、动作重置和姿势轮播。
- 复杂战斗拆成多个镜头，在动作结果、受力反馈或视觉焦点变化处切镜；下一镜从上一镜的结束方向、姿态、武器位置和空间状态接续，不重复起手，也不凭空跳过关键位移。
- 高速不等于混乱。相机运动、主体运动、特效运动分别说明；动作连贯优先于堆叠“震撼、炸裂、残影”等形容词。特效必须服务于命中、格挡、落地、破坏等可见结果。
- 时长按实际速度、运动距离与叙事需要分配，不能按招数机械地一招分配几秒。短距离连斩、格挡、反击可密集发生；长距离腾空、转场和完整大招不能瞬间完成，超载时按模型合法时长拆镜。

## 剧本阶段：把战斗写成事件，不写成概述

- 此节在本章确有战斗时强制执行，对招式和战斗表现的要求高于导演/画风手册中的冲突条款；不得据此改画风、改人物身份或凭空赋予新能力。
- 一场重要战斗写出“直接威胁 → 连续攻防 → 空间/优势变化 → 破绽与逆转 → 大招兑现 → 余势与代价”。短暂交手不硬套全套结构，但每次关键出招必须有可见应对和结果。不能用“双方激战数回合”“剑光纵横后获胜”跳过过程。
- 连招是一条因果链而非招式名单：写出身体哪个部位先动、脚下如何借力、兵器沿哪里运行、对方如何格挡或闪避、上招收势如何成为下招起势。一次交锋可包含连续几次有意义的攻守转换；不要把“一条主要动作链”误读为“一镜只能挥一下剑”。
- 例如：对手右爪斜压，女子左足蹬地滑向爪外侧，剑脊顺势贴爪卸力；爪落空砸裂石阶，她借前踏尚未收回的重心转髋回斩颈侧；对手缩颈以角架住剑锋，碰撞将她推回半步，她屈膝吸收冲击，以仍接触龙角的剑身为支点旋身脱离；龙尾循她落点横扫，她看见尾根绷紧才踏上断柱避让。后招由前招的接触、惯性、站位或破绽产生，不每句重新站回原位。
- 这段例子只示范攻防因果，不强制添加女子、神龙或同一套招式。对手也要有策略和反馈，不能静止承受整套连击。普通武功用身体与兵器反馈；神通才使用世界观允许的能量表现。
- 场地会留下结果：碎裂台阶、武器落点、遮挡烟尘、人物伤势和方向变化要延续到后文。赢在诱敌、借力、破防或付出代价，而不是突然宣布“力量更强”。

## 大招表现：特写蓄势、慢镜识破、实时释放

- 重要大招必须设计有叙事目的的特写与短暂慢镜节拍，不能只增加“炫酷、毁天灭地、震撼”形容词。小招不逐招慢放；整段持续慢放会削弱速度感。
- 起势/显形：特写手指结印、剑锋聚能、眼神锁定或支撑脚压裂地面，表现具体触发动作；切中景/全景展示能量从身体或武器沿明确路径形成。巨龙固定召唤入口、龙角鳞色和与施术者关系；法相用人物、建筑、投影与遮挡给出可信尺度。
- 施放/攻防：在识破破绽、擦身闪避或接触前一瞬短暂慢镜，突出剑锋距离、手腕转向、护甲裂纹或瞳孔反应；慢镜中动作仍连续推进，不冻结、不重复播放。随即明确恢复实时速度，让发力、突进和碰撞一气贯通。对手必须尝试阻挡、避让或付出代价。
- 命中/收束：接触点特写交代命中因果，再用中远景展示冲击沿何方向传递到身体、地面和环境；保留惯性、落地和恢复呼吸，给出下一镜可承接的最终姿态。大招不必一击获胜，威力与胜负服从剧情。
- 剧本可写“△特写：握剑的指节收紧……”“△短暂慢镜：剑锋擦过护甲，裂纹由接触点展开……”“△恢复实时：她借反震旋身落地……”。这些是画面表演说明，不是台词、字幕或招式喊话；后续分镜必须保留它们的叙事作用，视频提示词不得把标记本身当作屏幕文字。
- 将高密度交锋转化为清楚的时间与空间推进，保留近景拆招、巨物尺度、优势反转和收束；不把十秒七段当硬模板。一两秒可以容纳密集短距离连斩与拆招，但不能凭空完成多次长距离腾空与落地。大招按实际模型能力给关键特写、慢镜和恢复实时留出时长，必要时跨镜续接同一招式。

## 跟拍、换视角与战斗光影

- 高速移动交锋时，相机同步追拍并锁定交锋中心的构图和焦点，不是把相机固定在地面。明确跟随哪一方或双方中点、追拍方向、距离、高度及加减速节点；留下运动前方空间，保持人物轮廓、兵器和接触点可读，用背景视差表现速度，不靠猛烈摇晃制造刺激。
- 视角变化服务攻防信息：侧向跟拍看连续变招，过肩看逼近与破绽，低机位看突进冲击，全景看空间位移和大招尺度。按实际时长和攻防转折偶尔变化，不机械地每招切镜；一段相机路径先执行清楚再转入下一段。
- 镜内可通过连续弧线跟拍换角度。已有明确剪辑设计时遵守其切点；粗略战斗段可在详细编排时补充动作匹配切点、新机位与轴线一侧，保持视线、运动方向、伤势和持物，不能重复挥砍或跳过碰撞。只有项目首帧模式开启的关联镜才先承接真实尾帧再移动相机；硬切新机位换组或留空。关闭时所有 continuity_group 留空，明确本镜完整开场与收尾状态，以实际资产参考独立生成，不能要求前镜尾帧。一个视频内部可有多个机位，完整连招尽量放在同一片段，不为每次换机位创建视频任务。
- 主光、环境光、光源色温和位置以场景坐标为准。换视角后画面左右的明暗关系可以改变，但光源不能跟着相机旋转。高速移动时阴影随身体和遮挡连续变化，保持曝光与肤色稳定；只有实际进入另一光区才改变照明。
- 剑光、火焰、雷光等招式光随蓄能、轨迹、接触与衰减作用于附近脸部、武器、地面；轮廓光必须有光源依据。大招可增强尺度与光影层次，不以全屏泛白、随机频闪或过量粒子掩盖人物。
- 审核跟拍丢失主体、无因越轴、切镜时动作重置、光源漂移与曝光闪烁。用户明确固定机位时仍保持固定。剧本用动作与可见光影表达，具体机位和组标识在分镜阶段记录。

## 视频提示词执行

- 招式图只提供无人特效、武器、能量结构或召唤物，不承载施术人物和空间构图。按 reference_map 的 owner_name/relationship 指定招式归属，并在当前镜头写清人物参考编号、释放手/武器/发力点、目标方向、相对尺度和前后遮挡；人物性别、面容与服装由人物图及真实尾帧决定。旧招式图即使有人物也不能复制其人物，不能增加施术者或更换身份。

- 读取当前模型的参考图数量、图片格式、时长、分辨率、音频和生成模式契约。仅实际提供的真实首帧/前镜尾帧作为 0.00 秒图片引用；其余角色、武器和场景图按实际 `reference_map` 显式引用，不能只在文字里提到。
- 视频提示词必须覆盖完整动作链和邻镜衔接。不要凭空加入对白、音乐、音效或语言；声音只使用平台明确提供并允许上传的音频及对白锁。
- 保持角色和生物外观连续，破坏、火花、烟尘、碎片和光效只能发生在动作逻辑允许的时刻，不得遮蔽首帧身份或造成随机变形。
- 本技能不指定固定英文格式。主体语言服从模型契约，台词保持原文。

## 输出检查

逐镜确认：有首帧静态状态；有可执行动作轨迹；有攻防和受力反馈；有明确结束状态；与前后镜头连续；引用数量和格式合法；时长合法；音频与对白没有未经授权的新增内容。

审核普通交锋的动作密度与速度：无剧情原因却在数秒到十几秒只出一两招、每招复位等候、普通招式整段慢放，均列为 major，定位并修复为有因果的连续变招；不靠堆叠“刺激、爽、快速”替代具体动作。


当前镜头明确的静止主体、固定摄影机、静止环境分别执行，优先于通用动感和打斗建议。粗略战斗段授权补全攻防与运镜，但不能更改明确静止约束或剧情结果。资产参考图只约束身份外观和招式特征，不作为全幅开场构图。
